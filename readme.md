# Switch

An MCP server *and* a complete app that plugs India's RBI-regulated Account Aggregator network into any LLM. Connect your bank via consent-based AA, and Switch handles the rest — fetching, categorizing, and remembering your finances so any LLM (Claude, ChatGPT, or your own dashboard) can answer real questions grounded in your real data.
